# StickerBoard 🚧 (Beta)

**Your stickers. Your keyboard.**

StickerBoard is an open-source iOS app that lets you import your favorite stickers and access them directly from a custom third-party keyboard.

No more switching between apps to find your stickers. Just open your keyboard, pick a sticker, and send it!

## Project Status

StickerBoard is currently in **Beta** and is under active development.

This project started as a way to learn SwiftUI and iOS development through building something practical.

However, the goal goes beyond learning. I'd love to turn StickerBoard into a polished app and potentially publish it on the App Store someday.

## ✨ Planned Features

- Import and manage personal stickers.
- Custom sticker names for easier searching.
- Dedicated third-party keyboard.
- Quick sticker access from any supported app.
